# 素材收录

把正在看的 X（Twitter）贴文一键存到本地，之后在本地网页里回看、拿去创作。数据只存在你自己的电脑上。

由两部分组成：一个 Chrome 扩展负责读取当前贴文，一个本地小服务负责把正文和图片、视频存进 `library/` 文件夹并提供浏览页。

## 第一次使用

1. 需要 Python 3.10，这台机器上在 `D:\Install\py310\python.exe`。不需要装任何第三方包。
2. 双击 `start.bat`。第一次运行会用上面的解释器自动创建 `.venv` 虚拟环境，之后都走虚拟环境里的 Python，不再依赖 `py` 启动器（它默认指向的 `C:\Python312\python.exe` 已不存在）。窗口里出现 `素材库已启动： http://127.0.0.1:8787/` 就行了，这个窗口要一直开着，关掉它服务就停了。
3. 打开 Chrome，地址栏输入 `chrome://extensions`，打开右上角「开发者模式」，点「加载已解压的扩展程序」，选中本目录下的 `extension` 文件夹。扩展图标在第一次运行 `start.bat` 时自动生成，如果加载时提示缺图标，先运行一次 `start.bat` 再加载。
4. 打开任意一条 X 贴文的详情页（地址形如 `x.com/某人/status/数字`），点工具栏里的扩展图标，再点「收录」。也可以用快捷键 `Alt+S`。

浏览已收录的素材：浏览器打开 <http://127.0.0.1:8787/>。可以按正文或作者搜索。

## 收录了什么

- 正文全文（长文不会被截断）、作者显示名和用户名、发布时间、原贴链接。
- 图片按原图尺寸下载，视频下载清晰度最高的 mp4。

同一条贴文重复收录不会产生第二份。如果下载中途断了，重启服务后再收录一次，会把没下完的补上。

## 做不到的事

- 必须是贴文详情页。在首页时间线上点收录会提示先打开贴文。
- 少数视频只提供流媒体地址（m3u8），没有 mp4，这类视频会跳过并在收录结果里说明，正文仍会保存。
- 不收录评论、不做标签。

## 文件存在哪

全部在 `library/` 下，一条贴文一个文件夹：`tweet.json` 是正文和作者，`media-1.jpg`、`media-2.mp4` 这类是媒体文件。可以直接复制整个文件夹做备份。

## 自测

不访问 X、不需要开浏览器：

```
.venv\Scripts\python.exe server\selftest.py
```

它用一份写死的 GraphQL 响应验证贴文提取（长文、原图、最高码率视频、跳过评论），再起一个临时服务验证落盘、重复收录和非法地址拒绝。输出 `全部通过` 即正常。
